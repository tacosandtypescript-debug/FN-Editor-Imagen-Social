Bandeja de publicaciones

Cómo funciona la bandeja

El sistema no convierte nada automáticamente: primero trae las publicaciones y tú eliges cuáles se convierten en tarjeta. La lista va de más reciente a más antigua, agrupada por día. Lo que ya procesaste desaparece de la vista, y cada publicación se recuerda para no volver a aparecer aunque se limpie.

Tarjetas procesadas

Qué puedes hacer con una tarjeta

Aquí quedan todas las tarjetas que ya creaste, aunque hayan salido de la bandeja de pendientes. Desde aquí puedes abrir el editor, volver a generar el texto y los colores con tu suscripción, enviarlas a Telegram o descargarlas. Al pulsar «Procesar» primero verás tres pares de textos generados por el CLI de ChatGPT y elegirás uno antes de componer.

Selecciona una publicación en la bandeja para analizarla y crear su tarjeta.

Cuentas monitoreadas

Análisis con IA (tu suscripción)

El proveedor preferido es el CLI de Codex que ya está instalado y con sesión iniciada en este equipo: consume tu suscripción de ChatGPT, no una clave de API de pago, y devuelve JSON validado. Genera el titular de arriba, el texto de abajo y los colores de las palabras y tres alternativas de par superior/inferior para elegir antes de componer.

Limpieza automática

Las publicaciones dejan de mostrarse al pasar el tiempo de retención, junto con sus imágenes y tarjetas. No se olvidan: se guarda un registro permanente de lo ya visto, así que no vuelven a aparecer como nuevas en la siguiente búsqueda. Además se detecta la misma noticia republicada con otro identificador.

Cómo se reutiliza el repositorio

  • Composición: bin/compose_image.py (sin modificarlo).
  • Descarga de medios: bin/fetch_media.py (orden, límite de 25 MB y validación originales).
  • Preset automático y validación de salida: funciones de bin/edit_link.py.
  • Entrega: PNG como documento (sendDocument), como indica el repositorio.
