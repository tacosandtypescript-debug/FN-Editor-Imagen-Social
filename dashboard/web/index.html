Cómo se reutiliza el repositorio

  • Composición: bin/compose_image.py (sin modificarlo).
  • Descarga de medios: bin/fetch_media.py (orden, límite de 25 MB y validación originales).
  • Preset automático y validación de salida: funciones de bin/edit_link.py.
  • Entrega: PNG como documento (sendDocument), como indica el repositorio.
