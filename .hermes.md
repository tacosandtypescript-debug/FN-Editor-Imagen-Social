# EditImg — reglas de trabajo para Hermes

Estas reglas son la entrada de proyecto para Hermes. El repositorio contiene
skills de proyecto en `.hermes/skills/`; no uses las copias antiguas de
`skills/media/` si la skill `fortnite-image-editor` está disponible.

## Enrutamiento obligatorio

- Si Isaac pega un enlace de `x.com`, `twitter.com`, una URL directa de imagen
  o adjunta imágenes y pide editar, cargar `fortnite-image-editor`.
- `cuadrada`, `1:1`, `feed` o `post cuadrado` significa `square-image-editor`.
- `vertical`, `9:16`, `story` o `historia` significa `vertical-image-editor`.
- Si no indica formato, usar vertical 9:16 (1080×1920).
- No detenerse después de descargar el enlace: descargar, componer, validar y
  entregar la tarjeta final en la misma petición.

## Flujo de enlaces

1. Obtener el texto del post con las herramientas disponibles antes de redactar
   el titular. No inventar datos que no aparezcan en el post.
2. Si Isaac envía dos o más enlaces en la misma petición, tratarlos como un
   único lote editorial/carrusel: usar `scripts/prepare_batch.py`, conservar el
   orden de los enlaces y de sus medios, y leer `sources[].post_text` antes de
   redactar. No crear un titular por enlace ni mezclar el orden de las fuentes.
   El límite total del lote es 24 imágenes.
3. Crear un único titular general que abarque todos los posts del lote (3–12
   palabras), y una única línea inferior compartida con contexto y fecha. Para
   una sola fuente, mantener el titular de 3–7 palabras. No inventar temas que
   no aparezcan en los textos obtenidos.
4. El texto normal es blanco. Marcar con `{PALABRA|HEX}` únicamente palabras
   semánticamente importantes; nunca colorear artículos, preposiciones,
   conjunciones o pronombres como `de`, `la`, `los`, `a`, `o`, `y`, `que`, `se`.
   Usar como máximo dos colores de acento. `--top` y `--bottom` nunca pueden
   estar vacíos.
5. En un lote, usar `compose_image.py` una sola vez con todas las imágenes del
   manifiesto. Usar `--fit contain` para no recortar ni hacer zoom en capturas;
   el compositor reserva zonas seguras arriba y abajo para que el texto no
   desaparezca.
6. Crear además un único caption para todo el carrusel, separado de la imagen:
   título general + fecha + exactamente cinco hashtags únicos, uno de ellos
   `#khetzalgg`. Para los otros cuatro, consultar el TikTok Creative Center
   oficial del día, preferentemente con región España e industria Gaming/
   Fortnite (`https://ads.tiktok.com/business/creativecenter/inspiration/popular/hashtag/pc/en`);
   elegir solo etiquetas relacionadas con el contenido real. Si la consulta no está disponible, no inventar que una etiqueta es viral: usar
   etiquetas relevantes verificables y avisar de que la tendencia no se pudo
   confirmar. No poner los cinco hashtags dentro de la imagen.
7. Ejecutar `verify_image.py` y no entregar el resultado si falla.
8. Entregar el PNG original como documento cuando la superficie lo permita; no
   sustituirlo por una foto comprimida.

## Límites

- El compositor canónico de las skills Hermes vive dentro de cada skill en
  `.hermes/skills/*/scripts/`; no dependas de `bin/` ni de `barlow_font/`.
- La publicación en Instagram solo ocurre si Isaac la solicita explícitamente
  y requiere la skill `editar-publicar-instagram`, que es Linux-only.
- Las reglas de la skill activa tienen prioridad sobre una interpretación
  genérica del pedido, pero una instrucción explícita de Isaac sobre formato,
  texto o cantidad de imágenes tiene prioridad sobre los valores por defecto.

Si se instala o modifica una skill durante una conversación, iniciar una nueva
sesión o usar `/reset` antes de verificarla.
