# EditImg — reglas de trabajo para Hermes

Estas reglas son la entrada de proyecto para Hermes. El repositorio contiene
skills de proyecto en `.hermes/skills/`; no uses las copias antiguas de
`skills/media/` si la skill `fortnite-image-editor` está disponible.

## Comando de entrada

El comando oficial para iniciar una edición es:

```text
/imagen <enlace-1> [enlace-2] [enlace-3] ...
```

`/imagen` es un bundle de Hermes que carga `fortnite-image-editor`. Si el alias
todavía no aparece, registrar una vez desde la raíz del repositorio:

```text
hermes bundles create imagen --skill fortnite-image-editor --description "Editor de imágenes sociales 4K"
```

`<enlace-1>` es obligatorio y los demás enlaces son opcionales. Se pueden
escribir separados por espacios o en líneas diferentes. No escribir los
corchetes: son solo marcadores. `/imagen` activa `fortnite-image-editor` y
significa “descargar, editar, validar y entregar” cada publicación; no pedir
otra confirmación sobre qué hacer con los enlaces salvo que Isaac indique una
acción distinta.

Ejemplos:

```text
/imagen https://x.com/cuenta/status/123
/imagen https://x.com/cuenta/status/123 https://x.com/cuenta/status/456
```

El formato predeterminado es automático en 4K: vertical para fuentes
verticales, cuadrado para fuentes cuadradas y horizontal para fuentes
apaisadas. Para forzar un formato, añadir `vertical`, `cuadrada`/`1:1` o
`horizontal`/`16:9` en el mismo mensaje. Cada enlace sigue siendo una
publicación independiente.

## Enrutamiento obligatorio

- Si Isaac pega un enlace de `x.com`, `twitter.com`, una URL directa de imagen
  o adjunta imágenes y pide editar, cargar `fortnite-image-editor`.
- `cuadrada`, `1:1`, `feed` o `post cuadrado` significa `square-image-editor`
  y exportación 4K `2160×2160`.
- `vertical`, `9:16`, `story` o `historia` significa `vertical-image-editor`
  y exportación 4K `2160×3840`.
- `horizontal`, `16:9`, `apaisada` o `panorámica` significa salida horizontal
  y exportación 4K `3840×2160`.
- Si no indica formato, usar `auto`: contar la orientación de las imágenes de
  cada publicación. Gana la orientación mayoritaria; si hay empate entre
  vertical y horizontal, usar cuadrado `2160×2160`.
- No detenerse después de descargar el enlace: descargar, componer, validar y
  entregar la tarjeta final en la misma petición.

## Unidad de trabajo y entrega

- Cada enlace de X representa una publicación independiente.
- Si Isaac envía cuatro enlaces, generar cuatro salidas y enviarlas como cuatro
  documentos separados, en el mismo orden recibido.
- Si una publicación contiene 1, 2 o 3 imágenes, juntar únicamente esas imágenes
  en una tarjeta 4K. Nunca mezclar imágenes de publicaciones distintas.
- Solo combinar publicaciones distintas en un carrusel/tarjeta global si Isaac
  lo pide explícitamente con esas palabras.

## Comunicación con Isaac

- Enviar un único estado persistente en español para toda la petición. Si la
  superficie permite editarlo, actualizar el mismo mensaje, por ejemplo:
  `⏳ Preparando 4 publicaciones…` → `🔄 2/4 listas…` → `✅ 4/4 listas`.
- No enviar un mensaje nuevo por cada comando, búsqueda, inspección, descarga,
  render, validación u optimización interna. Esas acciones son internas.
- Si no se puede editar el estado, enviar como máximo un aviso inicial y un
  resumen final; no mostrar la lista de pasos en inglés.

## Flujo de enlaces

1. Obtener el texto del post con las herramientas disponibles antes de redactar
   el titular. No inventar datos que no aparezcan en el post.
2. Si Isaac envía dos o más enlaces en la misma petición, usar
   `scripts/prepare_batch.py` para descargar el conjunto, pero procesar cada
   elemento de `sources[]` como una publicación independiente. Mantener el
   orden y no usar la lista plana `images` para mezclar fuentes. Cada fuente
   admite hasta 24 medios. El manifiesto devuelve `recommended_format` y
   `recommended_4k_dimensions` para que el agente no tenga que adivinar el
   formato.
3. Crear un titular, contexto, fecha y caption por publicación. El titular de
   una publicación debe abarcar todas sus imágenes (3–12 palabras si contiene
   varias); no crear un titular por imagen. No inventar temas que no aparezcan
   en el texto de esa fuente.
4. El texto normal es blanco. Marcar con `{PALABRA|HEX}` únicamente palabras
   semánticamente importantes; nunca colorear artículos, preposiciones,
   conjunciones o pronombres como `de`, `la`, `los`, `a`, `o`, `y`, `que`, `se`.
   Usar como máximo dos colores de acento. `--top` y `--bottom` nunca pueden
   estar vacíos.
5. Para cada fuente, usar `compose_image.py` una vez con todas las imágenes de
   `sources[i].images`. Si el formato no fue indicado, pasar `--format auto` y
   elegir el preset correspondiente a la orientación detectada. Usar `--fit
   contain` para no recortar ni hacer zoom en capturas; el compositor reserva
   zonas seguras arriba y abajo para que el texto no desaparezca.
6. Crear un caption separado para cada publicación: título de esa publicación
   + fecha + exactamente cinco hashtags únicos, uno de ellos `#khetzalgg`.
   Para los otros cuatro, consultar el TikTok Creative Center oficial del día,
   preferentemente con región España e industria Gaming/Fortnite
   (`https://ads.tiktok.com/business/creativecenter/inspiration/popular/hashtag/pc/en`);
   elegir solo etiquetas relacionadas con el contenido real. Si la consulta no
   está disponible, no inventar que una etiqueta es viral: usar etiquetas
   relevantes verificables y avisar de que la tendencia no se pudo confirmar.
   No poner los cinco hashtags dentro de la imagen.
7. Ejecutar `verify_image.py` con las dimensiones 4K del formato y no entregar
   el resultado si falla.
8. Entregar cada PNG 4K como **documento/archivo independiente**. Si Telegram
   ofrece `sendPhoto` y `sendDocument`, usar `sendDocument`; nunca enviar la
   tarjeta como foto o previsualización comprimida.

## Límites

- El compositor canónico de las skills Hermes vive dentro de cada skill en
  `.hermes/skills/*/scripts/`; no dependas de `bin/` ni de `barlow_font/`.
- La publicación en Instagram solo ocurre si Isaac la solicita explícitamente
  y requiere la skill `editar-publicar-instagram`, que es Linux-only.
- Las reglas de la skill activa tienen prioridad sobre una interpretación
  genérica del pedido, pero una instrucción explícita de Isaac sobre formato,
  texto o cantidad de imágenes tiene prioridad sobre los valores por defecto.

Si se instala o modifica una skill durante una conversación, iniciar una nueva
sesión o usar `/reset` antes de verificarla.
