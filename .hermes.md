# EditImg — reglas de trabajo para Hermes

Estas reglas son la entrada de proyecto para Hermes. El repositorio contiene
skills de proyecto en `.hermes/skills/`; no uses las copias antiguas de
`skills/media/` si la skill `fortnite-image-editor` está disponible.

## Enrutamiento obligatorio

- Si Isaac pega un enlace de `x.com`, `twitter.com`, una URL directa de imagen
  o adjunta imágenes y pide editar, cargar `fortnite-image-editor`.
- `cuadrada`, `1:1`, `feed` o `post cuadrado` significa `square-image-editor`.
- `vertical`, `9:16`, `story` o `historia` significa `vertical-image-editor`.
- Si no indica formato, usar vertical 9:16 (1080×1920).
- No detenerse después de descargar el enlace: descargar, componer, validar y
  entregar la tarjeta final en la misma petición.

## Flujo de enlaces

1. Obtener el texto del post con las herramientas disponibles antes de redactar
   el titular. No inventar datos que no aparezcan en el post.
2. Descargar todos los medios en su orden original. Si hace falta obtener el
   texto desde el paquete, usar `.hermes/skills/*/scripts/prepare_link.py`,
   leer su JSON y continuar inmediatamente con `compose_image.py`; el límite
   operativo por defecto es 24 imágenes.
3. Crear un titular de 3–7 palabras y un contexto breve si Isaac no proporciona
   textos. Mantener como máximo dos colores de acento.
4. Usar el `edit_link.py` autocontenido de la skill elegida, con su preset y
   formato explícitos, o `compose_image.py` si ya se ejecutó `prepare_link.py`.
5. Ejecutar `verify_image.py` y no entregar el resultado si falla.
6. Entregar el PNG original como documento cuando la superficie lo permita; no
   sustituirlo por una foto comprimida.

## Límites

- El compositor canónico de las skills Hermes vive dentro de cada skill en
  `.hermes/skills/*/scripts/`; no dependas de `bin/` ni de `barlow_font/`.
- La publicación en Instagram solo ocurre si Isaac la solicita explícitamente
  y requiere la skill `editar-publicar-instagram`, que es Linux-only.
- Las reglas de la skill activa tienen prioridad sobre una interpretación
  genérica del pedido, pero una instrucción explícita de Isaac sobre formato,
  texto o cantidad de imágenes tiene prioridad sobre los valores por defecto.

Si se instala o modifica una skill durante una conversación, iniciar una nueva
sesión o usar `/reset` antes de verificarla.
